# AuraStackColorTest

独立的正式服测试插件。监测玩家自身的 390787（祸福相依）增益，在屏幕中央显示完整的 `█`：1 层白色，8 层黑色；实际光环达到 9–10 层时继续显示黑色。无光环时显示灰色字符。

## 安装

将整个 `AuraStackColorTest` 目录复制到游戏的 `Interface/AddOns/`，保持 `.toc` 与 `.lua` 文件位于同一目录。进入游戏或输入 `/reload` 后，中央应出现灰色字符。插件无需 Fuyutsui 或 Shigure。

## 验证重点

1. 获得 390787 后观察 1–8 层的颜色变化。若 1 层仍为灰色，说明层数文本可能在 1 层时被隐藏。
2. 若各层都显示同一种颜色或出现字面量 `|c...`，说明层数格式器输出的颜色标记未被正确渲染。
3. 测试不同 UI 缩放时字符是否完整，以及截图中的 RGB 是否稳定。

此插件只验证 `NumericRuleFormatter` → `SetApplicationCount` → `FontString` 的显示链路，不读取光环的秘密值，也不更改现有插件配置。
